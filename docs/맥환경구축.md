# 1. Homebrew 설치
맥에서 프로그램과 개발 도구를 설치·업데이트·삭제해주는 패키지 관리자  

Homebrew는 Apple Silicon 맥에서는 일반적으로 /opt/homebrew 아래에 프로그램을 각각 분리해 저장한 뒤, 터미널에서 실행할 수 있도록 연결한다고 한다.  

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Enter 누르고 설치하면  
==> Next steps:
- Run these commands in your terminal to add Homebrew to your PATH:
    echo >> /Users/a454676/.zprofile
    echo 'eval "$(/opt/homebrew/bin/brew shellenv zsh)"' >> /Users/a454676/.zprofile
    eval "$(/opt/homebrew/bin/brew shellenv zsh)"
- Run brew help to get started
- Further documentation:
    https://docs.brew.sh

    위와같이 뜬다.
    Next steps 의 명령어를 다시 입력한다.


그 다음 파이썬 버전 관리를 위헤
```bash
brew install pyenv
```

pyenv 를 터미널에 연결
```bash
pyenv init --install
```

현재 터미널 다시 시작
```bash
exec "$SHELL"
```

```bash
pyenv --version
```


```bash
cd ~/Projects/simple-rag

a454676@454676ui-MacBookPro rag_test % echo $SHELL
>> 결과
/bin/zsh

# source는 설정 파일의 내용을 현재 터미널에 즉시 다시 적용하라는 명령 (터미널을 껐다 키지 않아도 적용하기 위함)
source ~/.zprofile
# ~/.zprofile에는 보통 Homebrew처럼 터미널 경로를 설정하는 내용이 들어간다.
source ~/.zshrc
# ~/.zshrc에는 보통 pyenv 초기화, 별칭, 터미널 표시 설정 등이 들어간다.


# 환경 설정 확인
which brew
which pyenv
#

a454676@454676ui-MacBookPro rag_test % pyenv install 3.12.10
pyenv: /Users/a454676/.pyenv/versions/3.12.10 already exists

# 설치 중 아래와 같은 에러가 났다.
ModuleNotFoundError: No module named '_lzma'
WARNING: The Python lzma extension was not compiled.
# 라이브러리 먼저 설치해야 한다.

# 불완전 하게 설치된 파이썬 제거
pyenv uninstall -f 3.12.10
## 참고로 여기서 지우는 파이썬은
## macOS 시스템 Python이 아니라, pyenv가 설치한 3.12.10만

# 누락되었던 라이브러리 설치 (맥 터미널이든 vscode 터미널이든 무관하다.)
brew install xz

# 다시 파이썬 설치
pyenv install 3.12.10

# (vsCode terminal 에서) 해당 프로젝트의 파이썬 버전 지정
pyenv local 3.12.10
>> 결과 : 이렇게 하면 자동으로 .python-version 파일이 생성된다

# 설정확인
pyenv version
python --version

# 누락되었었던 라이브러리도 정상 인지 확인
python -c "import lzma; print('lzma OK')"

# 가상환경 생성
python -m venv .venv
source .venv/bin/activate

# 다시 설정 확인 (정상적으로 가상환경 패스를 잡는 지 확인한다.)
which python
python --version
```

# 3. Mac docker 설치
맥은 로그상 Apple Silicon 계열이므로 Mac with Apple silicon용 Docker Desktop을 설치

```bash
# (vsCode Terminal 에서)
brew install --cask docker

>> 결과: password (Mac 기기) 입력 시 정상 설치된다.

# docker 버전 확인
docker --version
docker compose version
```

# 4. OpenSearch 사용
```bash
# yml 파일 만들기
compose.yml

# 이미지 실행 : -d 터미널을 점유하지 않고 백그라운드에서 실행
docker compose up -d

# 실향 상태 확인
docker compose ps

# OpenSearch 접속 확인
curl http://localhost:9200
```
